# Content examples

These example files are instructions, not public content pages. Keep `published: false` until genuine material has been supplied and checked. Replace every REPLACE field before publishing. Copy the object into the appropriate JSON array and rebuild; do not rename these examples to HTML pages.

Articles require authentic text, author approval and supporting sources. Coverage requires a genuine original source and correct date. For coverage, leave `quote` empty to publish a source link without reproducing text. If quoting, record the permission or applicable lawful basis in `reuse_permission`. Use only public, non-sensitive notes in this public repository. Never copy private correspondence into the JSON.

The builder is deliberately small. It validates basic formats and escapes text, but cannot authenticate claims or provide legal permission. Phil must supply/approve the factual material.
